# AI Tool Usage Disclosure

AI tools (Claude and Antigravity) were utilized during this codebase refactor and audit. The tools were used to: (1) audit the codebase structure and business logic against assignment requirements, (2) identify two critical edge-case bugs — the waitlist promotion credit-validation bypass and the cross-table class overbooking flaw, and (3) implement and verify targeted fixes for both bugs via automated integration tests. All AI-assisted code edits, domain abstractions, and test results underwent manual review and verification prior to acceptance.
